# 9
المشروع المطلوب أكبر شوي من التاسك السابق؛ لأنه يجمع تحليل العملاء مع قاعدة البيانات والرسومات والتقرير النهائي. حتى تكون النتيجة صحيحة ومبنية على بياناتك الفعلية، بحتاج منك ملف قاعدة البيانات الحالي.
ارفع ملف store.db هون بالمحادثة. إذا اسم الملف مختلف، ارفع الملف اللي يحتوي على جدولي sales وproducts.
بعد ما ترفعه، بقدر أشتغل على قاعدة بياناتك نفسها وتجهيز الملفات التالية:
1. store.db المحدّث
إضافة 15 عميلًا على الأقل، وربط عمليات البيع الثلاثين بالعملاء مع إبقاء عميلين على الأقل بلا مشتريات، دون خسارة بياناتك الأصلية.



2. ملفات Python
ملف إعداد قاعدة البيانات، وملف التحليل الذي يحتوي على 8 استعلامات أو أكثر، باستخدام JOIN وSubquery وWindow Functions وGROUP BY.



3. أربعة رسوم أو أكثر
تحليل الإنفاق حسب العميل، والإيرادات الشهرية، وإيرادات الفئات، وعلاقة تاريخ التسجيل بالإنفاق، مع رسم تفاعلي باستخدام Plotly.



4. customer_analysis_report.xlsx
ملف Excel منظم بعدة صفحات، مع Summary تتضمن أهم الأرقام والنتائج الفعلية.



5. README.md
شرح المشروع، أهم الرؤى، توصية تجارية مبنية على النتائج الحقيقية، وخطوات تشغيل المشروع.



ليش بحتاج قاعدة البيانات؟ لأنني ما بدي أعطيك أرقامًا افتراضية وأكتبها في التقرير وكأنها نتائج متجرك. لازم نعرف أسماء الأعمدة الفعلية، ونحسب الإنفاق ونسبة العملاء المتكررين وأفضل الفئات والمدن من بياناتك.
ارفع الملف، وسأبني الحل على قاعدة بياناتك بدل ما نبدأ من الصفر ببيانات تجريبية.
